# Glossario

Definizioni operative. Per i dettagli usa la nota canonica collegata.

| Termine | Definizione breve |
|---|---|
| asset | elemento con valore da proteggere |
| attack surface | punti attraverso cui un sistema può essere influenzato |
| autenticazione | verifica dell'identità dichiarata |
| autorizzazione | decisione sulle azioni consentite |
| controllo | misura preventiva, detective, correttiva o di recovery |
| detection | logica che trasforma telemetria in segnale investigabile |
| finding | condizione osservata con evidenza, impatto e remediation |
| IOC | artefatto osservabile associabile a comportamento malevolo |
| least privilege | concedere solo capacità necessarie, per il tempo necessario |
| rischio | probabilità e impatto di uno scenario nel contesto |
| scope | perimetro esplicitamente incluso ed escluso |
| telemetria | eventi e misure prodotti da sistemi e applicazioni |
| threat | causa potenziale di danno |
| trust boundary | confine in cui cambia livello di fiducia o autorità |
| vulnerabilità | debolezza che può contribuire a uno scenario di rischio |

## Informatica e ingegneria

| Termine | Definizione breve |
|---|---|
| ABI | contratto binario tra programma, librerie e sistema operativo |
| API | contratto con cui un componente espone funzioni, dati o servizi |
| artefatto | risultato identificabile di un processo tecnico: binario, pacchetto, report o modello |
| cache | memoria temporanea di dati costosi da recuperare o calcolare |
| CI/CD | integrazione, verifica e distribuzione automatizzate |
| concorrenza | avanzamento sovrapposto di più attività, non necessariamente simultaneo |
| consistenza | proprietà che stabilisce quanto e quando osservatori diversi vedono lo stesso stato |
| deadlock | blocco permanente tra attività che attendono reciprocamente risorse |
| encoding | regola che associa informazioni a una rappresentazione, per esempio UTF-8 |
| endianness | ordine dei byte di un valore multibyte |
| idempotenza | ripetere un'operazione produce lo stesso effetto osservabile della prima esecuzione |
| IPC | tecniche di comunicazione e sincronizzazione tra processi |
| latenza | tempo tra input o richiesta e risposta osservabile |
| race condition | errore dipendente dall'ordine temporale non deterministico di attività concorrenti |
| RAG | generazione assistita dal recupero di fonti pertinenti |
| rollback | ripristino controllato di una versione o configurazione precedente |
| sandbox | ambiente isolato che limita risorse e capacità disponibili |
| SBOM | inventario strutturato di componenti e dipendenze software |
| schema | descrizione formale della struttura e dei vincoli dei dati |
| SLI | misura quantitativa di un comportamento del servizio |
| SLO | obiettivo misurabile associato a uno o più SLI |
| system call | richiesta di un processo al kernel per un'operazione privilegiata |
| threat model | modello di asset, attori, confini di fiducia, minacce e mitigazioni |
| Zero Trust | verifica esplicita, privilegi minimi e nessuna fiducia implicita dovuta alla rete |
