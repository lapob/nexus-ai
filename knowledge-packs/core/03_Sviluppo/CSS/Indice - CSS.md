# CSS

CSS governa layout e adattamento. Progetta dal contenuto e verifica dimensioni, zoom, input e contrasto.

## Da padroneggiare

- cascade, specificità, inheritance e custom properties;
- box model, flexbox e grid;
- unità relative, container/media query;
- overflow, wrapping e contenuti localizzati;
- stati focus/hover/disabled;
- reduced motion e contrasto;
- DevTools e rendering performance.

**Gate:** interfaccia leggibile da 320 px a desktop, al 200% di zoom, con tastiera e testi lunghi.
