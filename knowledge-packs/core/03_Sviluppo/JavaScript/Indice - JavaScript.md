# JavaScript

JavaScript è un linguaggio event-driven usato nel browser e in Node.js. Studialo insieme a runtime, asincronia e confini di sicurezza.

## Da padroneggiare

- scope, closure, oggetti, prototipi e moduli;
- event loop, promise, async/await e cancellazione;
- DOM, eventi, state e rendering;
- fetch, error handling, timeout e retry;
- Node.js, filesystem e process lifecycle;
- TypeScript, test e tooling;
- XSS, dependency risk e gestione segreti.

**Gate:** client o tool Node testato che gestisce errori, timeout, input non fidato e cleanup.
