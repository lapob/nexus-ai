# Identity, Windows e Active Directory

Studia autenticazione/autorizzazione, Kerberos e NTLM, domain/forest/trust, utenti-gruppi-computer, GPO, ACL, delegation, PKI/AD CS, Entra ID/federation e hybrid identity.

## Difesa

Tiering/amministrazione separata, workstation privilegiate, MFA, LAPS, gMSA, limitazione protocolli legacy, hardening GPO, auditing, backup del directory service e monitoraggio di modifiche privilegiate.

## Assessment autorizzato

Valuta configurazioni e percorsi di privilegio con account e limiti concordati. Riduci query e traffico, evita cambiamenti persistenti, non estrarre materiale sensibile se non indispensabile e documenta cleanup/retest.
