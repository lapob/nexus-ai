## Secure SDLC

Requisiti di sicurezza, threat modeling, standard di coding, peer review, SAST/SCA/secret scanning, test dinamici, fuzzing, SBOM, firma degli artefatti, deployment sicuro e vulnerability disclosure.

## Aree di studio

- autenticazione, sessioni, autorizzazione e access control
- injection, XSS, CSRF, SSRF, deserializzazione e path traversal
- upload/download, parser, template e command execution
- API REST/GraphQL, rate limit e object-level authorization
- crittografia applicata e gestione chiavi
- business logic, race condition e multi-tenancy
- dipendenze e software supply chain

Riferimenti concettuali: OWASP Top 10, ASVS, API Security Top 10, SAMM, CWE e CERT secure coding. Vedi [[02_Cybersecurity/Web Security/Indice - Web Security|Web Security]] e [[03_Sviluppo/Sicurezza del software|Sicurezza del software]].
