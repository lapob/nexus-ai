# Preview 0.3.9 / Android 6.4.3

Questa Preview rende la conversazione coerente fra Web, Windows e Android:

- i messaggi dell'utente sono compatti, allineati a destra e chiaramente identificati;
- le risposte NexusNXS restano aperte, leggibili e collegate da un accento luminoso discreto;
- la cronologia Web conserva Markdown, formule, link, tabelle e blocchi di codice;
- il Web compone la formattazione mentre riceve lo stream senza mostrare Markdown grezzo;
- gli aggiornamenti del DOM sono limitati per mantenere fluide le risposte lunghe.

Le build Founder Preview non sostituiscono una release Stable firmata.
